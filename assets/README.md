# Senna Music – Assets

This directory contains visual resources used by the Senna Music application.

## Structure

- `branding/logo/` – Application logos and brand variations.
- `branding/icons/` – Application icons and brand-related icons.
- `ui/navigation/` – Sidebar and navigation icons.
- `ui/player/` – Music player icons and graphics.
- `ui/controls/` – General interface controls and action icons.

Keep original generated assets here. Do not overwrite originals when creating optimized or resized versions.
